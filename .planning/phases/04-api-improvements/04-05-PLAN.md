## Tokenizer Interface

From src/mlx.zig/src/tokenizer.zig:
```zig
pub fn decode(self: *Self, token_ids: []const u32) ![]const u8
```

Tokenizer needs to be passed through:
`InferenceContext.generateWithTimeout()` → `GenerationState.init()` → stored in state

## Key Design Decisions

1. **Tokenizer storage in GenerationState:** Change from `?*const anyopaque` to proper `?*Tokenizer` type
2. **Decoding strategy:** Decode accumulated tokens periodically (not every token for efficiency)
3. **Stop sequence checking frequency:** Can batch decode every N tokens, but check after every decode
4. **Logprobs token strings:** Deferred — populate with empty strings initially, decode later if needed

  <files>src/inference/generator.zig</files>
  <action>
    Replace the TODO placeholder (lines 317-338) with actual stop sequence checking:
    
    **Current stub code to replace:**
    ```zig
    // Stop sequence detection (API-01)
    try self.tokens_since_decode.append(allocator, next_token);
    
    const should_check = self.tokens_since_decode.items.len >= 1;
    
    if (should_check and self.options.stop_sequences.len > 0) {
        // TODO: Decode tokens_since_decode...

    ```
    
    **New implementation:**
    ```zig
    // Stop sequence detection (API-01)
    // Accumulate tokens for potential decode+check
    try self.tokens_since_decode.append(self.allocator, next_token);
    
    // Decode and check stop sequences if any are configured
    if (self.options.stop_sequences.len > 0 and self.tokenizer != null) {
        // Decode accumulated tokens to text
        const decoded_chunk = try self.decodeTokens(self.tokens_since_decode.items);
        defer self.allocator.free(decoded_chunk);
        
        // Append to decoded text buffer
        try self.decoded_text_buffer.appendSlice(self.allocator, decoded_chunk);
        
        // Clear tokens since they've been decoded
        self.tokens_since_decode.clearRetainingCapacity();
        
        // Check if decoded text ends with any stop sequence
        if (self.checkStopSequence()) {
            // Match found — halt generation
            self.is_complete = true;
            self.stop_reason = .stop;
            self.truncateStopSequence();
            
            // Log for debugging
            std.log.debug("Stop sequence matched, halting generation", .{});
            
            return null;
        }
    }
    ```
    
    **Key considerations:**
    1. Only decode when stop_sequences are configured (avoid overhead when not needed)
    2. Only decode when tokenizer is available (graceful degradation)
    3. Decode accumulated tokens, append to buffer, then check
    4. When matched: set complete flag, stop reason, truncate sequence, return null
    5. Free decoded chunk memory after appending to buffer
    
    **Edge cases to handle:**
    - Multi-token stop sequences (e.g., "\n\n" spanning multiple decode operations)
    - Stop sequence at the very beginning of generation
    - Empty stop_sequences array (should be no-op)
