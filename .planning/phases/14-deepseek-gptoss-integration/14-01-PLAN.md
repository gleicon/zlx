## Backend Selection Strategy

| Architecture | Backend | Reason |
|------------|---------|----------|
| qwen | MLX.zig | Proven stable, optimized |
| deepseek_v2_moe | llama.cpp | Better MoE support, GGUF ecosystem |
| gpt_oss | llama.cpp | Better sliding window attn support |
| llama | Either | llama.cpp has native support |

## Required Abstractions

1. **Backend**: Union of MlxBackend and LlamaBackend
2. **GenerationParams**: Backend-agnostic sampling parameters
3. **GenerationResult**: Token iterator + metadata (tokens/s, finish_reason)
4. **TokenIterator**: Streaming interface yielding tokens one at a time

    // src/backends/factory.zig
    const std = @import("std");

    pub const BackendPreference = enum {
        auto,      // Select based on architecture
        mlx,       // Force MLX.zig
        llama_cpp, // Force llama.cpp
    };
    
    /// Detect which backend to use for a given architecture
    pub fn detectBackendType(arch: registry.ModelArchitecture) BackendPreference {
        return switch (arch) {
            .qwen => .mlx,            // Qwen works best with MLX.zig
            .deepseek_v2_moe => .llama_cpp, // DeepSeek MoE better in llama.cpp
            .gpt_oss => .llama_cpp,   // GPT-OSS better in llama.cpp
            .llama => .llama_cpp,    // Native llama support
            .phi => .mlx,             // Phi works with MLX.zig
            .deepseek_v1 => .llama_cpp,
            .unknown => .auto,
        };
    }
    
    /// Create appropriate backend for model
    pub fn createBackend(
        allocator: std.mem.Allocator,
        model_path: []const u8,
        arch: registry.ModelArchitecture,
        preference: BackendPreference,
    ) !backend.Backend {
        const backend_type = if (preference == .auto)
            detectBackendType(arch)
        else
            preference;
        
        return switch (backend_type) {
            .mlx => createMlxBackend(allocator, model_path, arch),
            .llama_cpp => createLlamaBackend(allocator, model_path, arch),
            .auto => error.CannotAutoDetect,
        };
