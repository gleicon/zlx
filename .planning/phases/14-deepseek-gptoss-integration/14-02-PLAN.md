## llama.cpp Build Requirements

**Repository:** ggml-org/llama.cpp (stable tag, not master)
**Build System:** CMake with Metal support
**Output:** libllama.a (static library)
**Headers:** llama.h, ggml.h, ggml-metal.h

**CMake Options for macOS Metal:**
```bash
cmake -B build \
  -DLLAMA_METAL=ON \
  -DLLAMA_METAL_EMBED_LIBRARY=ON \
  -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_SHARED_LIBS=OFF
```

  <name>Task 3: Integrate llama.cpp build into build.zig</name>
  <files>build.zig</files>
  <action>
    Add llama.cpp CMake build to build.zig:
    
    ```zig
    // In build.zig, add llama.cpp build steps
    
    // 1. CMake configuration step for llama.cpp
    const llama_cpp_path = "src/llama.cpp";
    const llama_build_path = b.pathJoin(&.{ llama_cpp_path, "build" });
    
    // Create cmake command
    const cmake_cmd = b.addSystemCommand(&.{
        "cmake",
        "-B", llama_build_path,
        "-S", llama_cpp_path,
        "-DLLAMA_METAL=ON",
        "-DLLAMA_METAL_EMBED_LIBRARY=ON",
        "-DCMAKE_BUILD_TYPE=Release",
        "-DBUILD_SHARED_LIBS=OFF",
        "-DLLAMA_STANDALONE=OFF",
    });
    
    // Create build command
    const build_cmd = b.addSystemCommand(&.{
        "cmake",
        "--build", llama_build_path,
        "--config", "Release",
        "--parallel",
    });
    build_cmd.step.dependOn(&cmake_cmd.step);
    
    // Make main executable depend on llama.cpp build
    exe.step.dependOn(&build_cmd.step);
    
    // 2. Add library paths
    exe.addLibraryPath(.{ .path = b.pathJoin(&.{ llama_build_path, "bin" }) });
    
    // 3. Link static library
    exe.linkSystemLibrary("llama");
    
    // 4. Add include paths for @cImport
    exe.addIncludePath(.{ .path = b.pathJoin(&.{ llama_cpp_path, "include" }) });
    exe.addIncludePath(.{ .path = b.pathJoin(&.{ llama_cpp_path, "ggml", "include" }) });
    exe.addIncludePath(.{ .path = b.pathJoin(&.{ llama_cpp_path, "ggml", "src" }) });
    
    // 5. Link required frameworks for Metal
    exe.linkFramework("Metal");
    exe.linkFramework("Foundation");
    exe.linkFramework("QuartzCore");
    exe.linkFramework("Accelerate");
    
    // 6. Add C source dependencies
    // llama.cpp needs to be compiled before Zig code can @cImport it
    // This is handled by the cmake build step above
    ```
