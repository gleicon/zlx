## GPT-OSS Model Characteristics

**Architecture:** 20B total parameters, ~5B active, 32-expert MoE
**Special Features:** Sliding window attention, Yarn RoPE
**Quantization:** MXFP4 (from OpenAI), or Q4_K_M GGUF (from community)
**Context:** 131,072 tokens
**Size:** ~11GB for Q4_K_M GGUF format

## GGUF Availability

**Community GGUF Sources:**
1. bartowski/GPT-OSS-20B-GGUF - Community conversion (if available)
2. unsloth/GPT-OSS-20B-GGUF - Unsloth optimized (if available)
3. Manual conversion from OpenAI safetensors using llama.cpp convert script

**Fallback Strategy:**
- Primary: Download pre-converted GGUF from HuggingFace
- Secondary: Document manual conversion from safetensors
- Tertiary: Use MLX.zig path with native MXFP4 (if llama.cpp unavailable)

// LlamaBackend is model-agnostic - works with any llama.cpp-supported model

GPT-OSS specific considerations:

- Yarn RoPE supported via GGUF metadata
- MoE routing with 32 experts (different from DeepSeek's 64)

    ```zig
    // src/download/gptoss.zig
    const std = @import("std");
    const download = @import("mod.zig");
    const registry = @import("../models/registry.zig");
    
    pub const GptOssDownloadError = error{
        InvalidUrl,
        DownloadFailed,
        ChecksumMismatch,
        InsufficientDiskSpace,
    };
    
    /// Download GPT-OSS GGUF model with progress reporting
    pub fn downloadGptOssModel(
        allocator: std.mem.Allocator,
        cache_dir: []const u8,
        quantization: []const u8, // "Q4_K_M", "Q5_K_M", etc.
        progress_callback: ?*const fn (downloaded: u64, total: u64) void,
    ) ![]u8 {
        // Get download info from registry
        const info = registry.getDownloadInfo("gpt-oss-20b") orelse 
            return error.InvalidUrl;
        
        // Construct filename with quantization
        const filename = std.fmt.allocPrint(allocator, "GPT-OSS-20B-{s}.gguf", .{quantization}) 
            catch return error.OutOfMemory;
        defer allocator.free(filename);
        
        const output_path = try std.fs.path.join(allocator, &.{ cache_dir, filename });
        
        // Check if already exists
        if (std.fs.accessAbsolute(output_path, .{})) {
            std.log.info("GPT-OSS model already exists at {s}", .{output_path});
            return output_path;
        } else |_| {}
        
        // Ensure cache directory exists
        try std.fs.cwd().makePath(cache_dir);
        
        // Check disk space (need ~12GB free)
        const space = try getAvailableDiskSpace(cache_dir);
        if (space < 12_000_000_000) {
            return error.InsufficientDiskSpace;
        }
        
        // Download with resume support
        std.log.info("Downloading GPT-OSS-20B ({s}) - ~11GB, this may take a while...", .{quantization});
        
        for (info.urls) |url| {
            const result = download.downloadWithResume(
                allocator,
                url,
                output_path,
                info.expected_size_bytes,
                progress_callback,
            ) catch |err| {
                std.log.warn("Download from {s} failed: {s}", .{ url, @errorName(err) });
                continue;
            };
            
            if (result) {
                std.log.info("Download complete: {s}", .{output_path});
                return output_path;
            }
        }
        
        return error.DownloadFailed;
    }
    
    /// Get available disk space in bytes
    fn getAvailableDiskSpace(path: []const u8) !u64 {
        // Platform-specific implementation
        // macOS: statfs syscall
        // Linux: statvfs
        _ = path;
        return 100_000_000_000; // Placeholder: 100GB
    }
    
    /// Verify downloaded file integrity
    pub fn verifyGptOssModel(model_path: []const u8) !bool {
        // Check file can be loaded by llama.cpp
        // Try llama_model_load with no_gpu_layers, then immediately free
        _ = model_path;
        return true;
    }
    ```
