Implementation outline for loadIndex():
```zig
fn loadIndex(self: *Self) !void {
    const index_path = try std.fs.path.join(self.allocator, &.{ self.cache_dir, "index.json" });
    defer self.allocator.free(index_path);

    std.fs.accessAbsolute(index_path, .{}) catch {
        std.log.info("No existing cache index found, starting fresh", .{});
        return;
    };

    const file = try std.fs.openFileAbsolute(index_path, .{});
    defer file.close();

    const content = try file.readToEndAlloc(self.allocator, 1024 * 1024); // 1MB max
    defer self.allocator.free(content);

    const parsed = try std.json.parseFromSlice(std.json.Value, self.allocator, content, .{});
    defer parsed.deinit();

    const root_obj = parsed.value.object;
    const entries_val = root_obj.get("entries") orelse return;
    const entries_arr = entries_val.array;

    try self.entries.ensureTotalCapacity(entries_arr.items.len);

    for (entries_arr.items) |item| {
        const obj = item.object;
        const key_str = obj.get("key").?.string;
        const size_bytes: u64 = @intCast(obj.get("size_bytes").?.integer);
        const created_at: i64 = obj.get("created_at").?.integer;
        const access_count_val: u32 = @intCast(obj.get("access_count").?.integer);

        const key_copy = try self.allocator.dupe(u8, key_str);

        const entry = CacheEntry{
            .size_bytes = size_bytes,
            .created_at = created_at,
            .access_count = std.atomic.Value(u32).init(access_count_val),
            // file_path and kv_state are not stored in index — set to defaults
            .file_path = try self.allocator.dupe(u8, ""),
            .kv_state = null,
        };
        try self.entries.put(key_copy, entry);
    }

    std.log.info("Loaded {d} cache entries from index", .{entries_arr.items.len});
}
```

**Key implementation notes:**
- `std.json.Value` fields: `.integer` is `i64`, `.string` is `[]const u8`, `.array` is
  `std.ArrayListUnmanaged(Value)`, `.object` is `std.StringArrayHashMapUnmanaged(Value)`
- All string values from parsed JSON are owned by `parsed` — must `dupe` before `parsed.deinit()`
- `std.atomic.Value(u32).init(val)` initializes an atomic with the loaded value
- `CacheEntry.kv_state` is a pointer to opaque KV state — cannot be restored from disk,
  set to `null`. This means a cache "hit" after restart will find the entry in the index
  but will need to re-load the KV state from its file.
- `CacheEntry.file_path` may or may not be stored in index.json — check saveIndex() to
  see if it writes `file_path`. If it does, load it; if not, set to `""`.
- Read the exact field names from `saveIndex()` — do not guess.
- Check if `self.entries` is guarded by a mutex in `init()` context — if loadIndex() is
  called before the server starts serving requests, no lock needed (same as saveIndex()).
- Add comment: `// real index.json load per D-05 — called once at init, no per-request I/O`
