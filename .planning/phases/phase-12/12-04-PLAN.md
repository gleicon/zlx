# Plan 12-04: Small Machine Constraints

## Goal
Enable zlx to run on small machines (8-16GB RAM) by implementing memory-aware model selection, automatic TurboQuant activation, and context length limits.

## Background

**Current Problem:**
- 20B MoE models OOM on 16GB MacBooks
- No protection against loading too-large models
- No guidance on what models fit user's machine
- Users have to manually manage memory

**Target Hardware:**
- 8GB MacBook Air (M1/M2/M3)
- 16GB MacBook Pro/Air (most common)
- 16GB Mac mini

**MoE Model Memory Requirements:**

| Model | Weights | KV Cache (8K) | Total | Fits 8GB? | Fits 16GB? |
|-------|---------|---------------|-------|-----------|------------|
| Qwen2.5-Coder-1.5B | ~1GB | ~400MB | ~2GB | ✅ Yes | ✅ Yes |
| DeepSeek-Coder-V2-Lite | ~8GB | ~1.5GB | ~10GB | ❌ No | ⚠️ Maybe |
| DeepSeek + TurboQuant | ~8GB | ~350MB | ~9GB | ⚠️ Tight | ✅ Yes |
| GPT-OSS-20B | ~11GB | ~2GB | ~13GB | ❌ No | ⚠️ Tight |
| GPT-OSS + TurboQuant | ~11GB | ~450MB | ~12GB | ❌ No | ✅ Yes |

**Key Insight:** TurboQuant is REQUIRED for MoE models on 16GB machines.

## Implementation

### Task 1: Memory Detection (0.5h)

Add system memory detection at startup:
```zig
const SystemInfo = struct {
    total_ram_gb: f32,
    available_ram_gb: f32,
    has_gpu: bool,
    gpu_memory_gb: f32,
};

fn getSystemInfo() !SystemInfo {
    // macOS: use sysctl hw.memsize
    // Or: parse system_profiler SPHardwareDataType
    
    var info: SystemInfo = undefined;
    
    // Get total RAM
    var memsize: u64 = 0;
    var len: usize = @sizeOf(u64);
    std.os.sysctlbyname("hw.memsize", &memsize, &len, null, 0);
    info.total_ram_gb = @floatFromInt(memsize) / (1024 * 1024 * 1024);
    
    // Get available RAM (rough estimate)
    // Leave 4GB for OS and other apps
    info.available_ram_gb = info.total_ram_gb - 4.0;
    
    return info;
}
```

**Verification:**
- Correctly detects 8GB, 16GB, 32GB systems
- Reports available RAM after OS overhead

### Task 2: Memory Budget Calculator (0.5h)

Calculate if model fits:
```zig
const ModelRequirements = struct {
    model_id: []const u8,
    weights_gb: f32,
    kv_cache_per_1k_gb: f32,
    min_context: usize = 512,
    max_context: usize = 131072,
};

fn canLoadModel(
    model: ModelRequirements,
    system: SystemInfo,
    requested_context: usize,
    use_turboquant: bool,
) !struct { fits: bool, max_context: usize, reason: []const u8 } {
    // Calculate KV cache size for requested context
    var kv_cache_gb = model.kv_cache_per_1k_gb * (@floatFromInt(requested_context) / 1024.0);
    
    // Apply TurboQuant compression
    if (use_turboquant) {
        kv_cache_gb /= 4.6; // 4.6x compression
    }
    
    const total_required = model.weights_gb + kv_cache_gb + 1.0; // +1GB safety margin
    
    if (total_required > system.available_ram_gb) {
        // Calculate max possible context
        const max_kv_gb = system.available_ram_gb - model.weights_gb - 1.0;
        var max_context: usize = @intFromFloat((max_kv_gb / model.kv_cache_per_1k_gb) * 1024.0);
        if (use_turboquant) {
            max_context = @intFromFloat(@floatFromInt(max_context) * 4.6);
        }
        
        return .{
            .fits = false,
            .max_context = max_context,
            .reason = "Insufficient memory",
        };
    }
    
    return .{ .fits = true, .max_context = requested_context, .reason = "" };
}
```

### Task 3: Auto-Enable TurboQuant (0.5h)

Automatically enable TurboQuant when needed:
```zig
fn determineOptimalConfig(
    model: ModelRequirements,
    system: SystemInfo,
    user_context_request: ?usize,
) !struct {
    use_turboquant: bool,
    max_context: usize,
    warning: ?[]const u8,
} {
    // Check if model fits without TurboQuant
    const without_tq = try canLoadModel(model, system, user_context_request orelse 8192, false);
    
    if (without_tq.fits) {
        // Model fits without compression
        return .{
            .use_turboquant = false,
            .max_context = without_tq.max_context,
            .warning = null,
        };
    }
    
    // Try with TurboQuant
    const with_tq = try canLoadModel(model, system, user_context_request orelse 8192, true);
    
    if (with_tq.fits) {
        // Auto-enable TurboQuant
        return .{
            .use_turboquant = true,
            .max_context = with_tq.max_context,
            .warning = "TurboQuant auto-enabled for memory efficiency",
        };
    }
    
    // Model still doesn't fit
    return .{
        .use_turboquant = true,
        .max_context = with_tq.max_context,
        .warning = "Context limited to fit available memory",
    };
}
```
