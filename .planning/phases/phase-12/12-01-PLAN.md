# Plan 12-01: DeepSeek Weight Loading

## Goal
Implement complete weight loading for DeepSeek-Coder-V2-Lite from safetensors files, enabling the model to actually run inference instead of crashing with empty weight arrays.

## Background

**Current State:** `loadDeepSeekWeights()` in `src/inference/loader.zig` returns empty arrays:
```zig
return deepseek.DeepSeekWeights{
    .token_embedding = mlx.arrayNew(),  // Empty!
    .layers = try allocator.alloc(deepseek.DeepSeekLayer, 27),
    .norm = mlx.arrayNew(),             // Empty!
    .lm_head = mlx.arrayNew(),          // Empty!
};
```

**Why This Matters:** The architecture detection works (identifies as `deepseek_v2_moe`), but inference fails immediately because all weights are empty MLX arrays.

## Technical Details

### Weight File Structure

DeepSeek-Coder-V2-Lite uses:
- `model.safetensors.index.json` - Index file mapping weight names to shard files
- `model-00001-of-00002.safetensors` - First shard (~4GB)
- `model-00002-of-00002.safetensors` - Second shard (~4GB)

### Weight Naming Convention

Based on the error logs and HuggingFace model structure:

**Embedding & Output:**
- `model.embed_tokens.weight` → Token embedding table [vocab_size, hidden_size]
- `model.norm.weight` → Final layer norm [hidden_size]
- `lm_head.weight` → Output projection [vocab_size, hidden_size]

**Per-Layer Weights (27 layers):**
- `model.layers.{i}.input_layernorm.weight` → Pre-attention norm
- `model.layers.{i}.post_attention_layernorm.weight` → Post-attention norm

**MLA (Multi-head Latent Attention):**
- `model.layers.{i}.self_attn.q_proj.weight` → Query projection
- `model.layers.{i}.self_attn.kv_b_proj.weight` → Key-Value compressed projection
- `model.layers.{i}.self_attn.k_proj.weight` → Key projection (for GQA)
- `model.layers.{i}.self_attn.v_proj.weight` → Value projection (for GQA)
- `model.layers.{i}.self_attn.o_proj.weight` → Output projection
- `model.layers.{i}.self_attn.q_a_proj.weight` → Query latent projection (MLA)
- `model.layers.{i}.self_attn.q_b_proj.weight` → Query second projection (MLA)
- `model.layers.{i}.self_attn.kv_a_proj.weight` → KV latent projection (MLA)
- `model.layers.{i}.self_attn.kv_b_proj.weight` → KV second projection (MLA)

**MoE (Mixture of Experts):**
- `model.layers.{i}.mlp.gate.weight` → Expert router
- `model.layers.{i}.mlp.experts.{e}.gate_proj.weight` → Expert e up-projection
- `model.layers.{i}.mlp.experts.{e}.up_proj.weight` → Expert e gate-projection
- `model.layers.{i}.mlp.experts.{e}.down_proj.weight` → Expert e down-projection
- `model.layers.{i}.mlp.shared_expert.gate_proj.weight` → Shared expert
- `model.layers.{i}.mlp.shared_expert.up_proj.weight` → Shared expert
- `model.layers.{i}.mlp.shared_expert.down_proj.weight` → Shared expert

## Error Handling

**Missing Weights:**
- Log warning with weight name
- Check if optional (like bias terms)
- Fatal error if required weight missing

**Shape Mismatches:**
- Log expected vs actual shape
- Abort load with helpful error message

**Memory:**
- Check available RAM before loading
- Stream weights from disk if insufficient memory
- Use mmap for large weight files

## Dependencies

- MLX.zig with working `loadSafetensors()`
- DeepSeek transformer architecture (Phase 11-04)
- ~8GB free RAM for loading 8.3GB model

## Risks and Mitigations

| Risk | Mitigation |
|------|------------|
| Weight naming differs from expectation | Log all weight names on first load, create mapping table |
| Loading all 64 experts at once OOMs | Implement lazy expert loading |
| MLX safetensors API doesn't support partial loading | Load full file but only keep needed weights |
| Quantized weights need dequantization | Check if MLX handles automatically, otherwise add dequant layer |
