## Objective

Implement multi-model hot-swap allowing model switching without server restart, with memory budget validation and graceful transition.

**Purpose:** Enable users to use different models for different requests without restarting the server. Critical for multi-model workflows.
**Output:** Working model manager that can switch models on-demand with automatic memory validation.

## Context

@.planning/phases/05-multi-model-support/05-01-PLAN.md
@src/models/registry.zig
@src/inference/mod.zig
@src/api/handlers.zig

### Current State

- Model loaded once at startup via `--model` flag
- global_context holds single InferenceContext
- No mechanism to unload or switch models
- Request model name only validated against loaded model, not used for switching

### Target State

- ModelManager handles loading, switching, and unloading
- Request with different model name triggers automatic switch
- Switch waits for active generation to complete
- Memory checked before load — rejected if insufficient
- Switch times: <2s for 1.5B, <5s for 7B

    2. Add model switching logic:
       ```zig
       const requested_model = request.model;
       const current_model = manager.getCurrentModel();
       
       if (current_model == null or !std.mem.eql(u8, current_model.?, requested_model)) {
           // Need to switch
           if (!manager.canLoadModel(requested_model)) {
               return sendError(res, 503, "Insufficient memory to load model", ...);
           }
           
           manager.switchModel(requested_model) catch |err| {
               return sendError(res, 500, "Failed to load model", ...);
           };
           
           // Update global_context with new inference context
           ctx = global_context.?;  // Should be updated by manager
       }
       ```
    
    3. Add switch timeout:
       - If switch takes >30 seconds, return 503 error

       - Include model names in logs
    
    5. Handle concurrent requests during switch:
       - Other requests should wait (block on switch_mutex)
       - Or return 503 with "model switching in progress"
       - Choose based on UX preference — document decision
    
    Default choice: Block other requests on switch_mutex — simpler, clearer UX
