## Objective

Build a model registry that scans and catalogs all available models, providing complete metadata through the `/v1/models` endpoint.

**Purpose:** Enable users to discover available models without manual directory inspection. Foundation for multi-model support.
**Output:** Working model registry with enhanced `/v1/models` endpoint showing all available models with metadata.

## Context

@.planning/phases/04-api-improvements/04-05-SUMMARY.md
@src/api/handlers.zig
@src/api/types.zig
@src/inference/loader.zig

### Current State

- `/v1/models` only returns the currently loaded model
- Models are discovered only via `--model` CLI flag at startup
- No model metadata beyond name (size, memory requirements unknown)
- Model paths: `./models/` for local, `~/.cache/zlx/models/` for auto-downloaded (future)

### Target State

- Registry scans both model directories on startup
- Each model entry includes: id, size, status (available/loading/loaded), memory_required_mb
- `GET /v1/models` returns full catalog with proper OpenAI-compatible format
- Registry updates when models are loaded/unloaded
