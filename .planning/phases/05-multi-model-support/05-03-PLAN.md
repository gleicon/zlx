## Objective

Implement comprehensive memory management, enhanced health checks, and detailed metrics for production monitoring.

**Purpose:** Prevent OOM crashes, provide visibility into resource usage, enable monitoring integration. Critical for production deployment.
**Output:** Detailed health endpoint, memory-aware metrics, and Prometheus-compatible export format.

## Context

@.planning/phases/05-multi-model-support/05-02-PLAN.md
@src/api/metrics.zig
@src/api/handlers.zig

### Current State

- /v1/health returns basic JSON: {"status": "healthy", "model": "..."}
- Metrics track: requests, tokens, generation time, TTFT
- No memory breakdown (weights vs KV cache vs temporaries)
- No GPU memory visibility
- No Prometheus format export

### Target State

- /v1/health returns comprehensive status including:
  - status: "healthy" | "degraded" | "unhealthy"
  - model: currently loaded model id
  - gpu: available, metal_enabled, memory_total_mb, memory_free_mb
  - memory: used_mb, available_mb, components breakdown
  - checks: array of individual health check results
- Metrics include memory components and export to Prometheus format
- Memory warnings at >80% capacity

           // 1. GPA allocator
           var gpa = std.heap.GeneralPurposeAllocator(.{}){};
           defer _ = gpa.deinit();
           const allocator = gpa.allocator();
           
           // 2. Parse CLI args
           const config = try parseArgs(allocator);
           
           // 3. Init memory tracker (must be first — tracks all subsequent allocations)
           try memory.initGlobalTracker(allocator);
           defer memory.deinitGlobalTracker(allocator);
           
           // 4. Init model registry
           try models_mod.initGlobalRegistry(allocator);
           defer models_mod.deinitGlobalRegistry(allocator);
           
           // 5. Init model manager (needs registry and tracker)
           const registry = models_mod.getGlobalRegistry().?;
           const tracker = memory.getGlobalTracker().?;
           try manager_mod.initGlobalManager(allocator, registry, tracker);
           defer manager_mod.deinitGlobalManager(allocator);
           
           // 6. Init metrics
           metrics.initMetrics(allocator);
           
           // 7. Load initial model (via manager, which uses tracker)
           if (config.model_name) |name| {
               const manager = manager_mod.getGlobalManager().?;
               try manager.switchModel(name);
           }
           
           // 8. Start stats logging
           _ = try metrics.startStatsLogging(allocator, 10);
           
           // 9. Run server
           try api.runServer(allocator, server_config);
