# Phase 09 Plan 01: Configuration File System

## Objective
Create a robust configuration system that loads settings from `~/.config/zlx/config.json` or `./zlx.json` with proper priority chain: CLI flags > Environment variables > Config file > Defaults. Validate all config on startup with helpful error messages.

## Purpose
Enable users to persist their preferred settings in a config file rather than repeating CLI flags on every launch. Support the v1.1 "convenience" theme by making zlx behave like a proper production server.

## Output
- `src/config.zig` — Configuration loader with file/env/CLI merging
- `src/config_test.zig` — TDD tests for config loading
