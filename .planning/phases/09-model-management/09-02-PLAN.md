# Phase 09 Plan 02: Model Auto-Download

## Objective
Implement automatic model downloading from HuggingFace when a model isn't found locally. Support resume of interrupted downloads via HTTP Range requests, show progress indicators, run downloads in background without blocking inference, and verify checksums after completion.

## Purpose
Eliminate the manual step of downloading models. Users can simply run `zlx --model mlx-community/Qwen2.5-Coder-7B` and the model downloads automatically if not present. This is essential for the "it just works" UX of v1.1.

### Key Requirements from RESEARCH.md

**HuggingFace Model Format:**
- Models hosted at `https://huggingface.co/{org}/{repo}`
- Files to download: `config.json`, `tokenizer.json`, `*.safetensors`
- API endpoint: `https://huggingface.co/api/models/{org}/{repo}` (gets file list)
- Download URL: `https://huggingface.co/{org}/{repo}/resolve/main/{filename}`
- LFS files require special handling (redirect to CDN)

**HTTP Range Request Format:**
```
Range: bytes={start}-{end}
```
- Resume by checking existing file size, requesting from that offset
- Must handle 206 Partial Content response
- Fallback to full download if server doesn't support ranges

**Background Download Architecture:**
- Use std.Thread to spawn download workers
- Main thread continues serving requests
- Download manager tracks state (queued, downloading, completed, failed)
- Registry status updated asynchronously

       ```zig
       pub fn downloadFile(
           allocator: Allocator,
           url: []const u8,
           dest_path: []const u8,
           progress_callback: ?*const fn (downloaded: u64, total: u64) void,
       ) !void {
           // Check existing file size for resume
           var start_byte: u64 = 0;
           if (std.fs.cwd().access(dest_path, .{})) {
               const file = try std.fs.cwd().openFile(dest_path, .{});
               defer file.close();
               const stat = try file.stat();
               start_byte = stat.size;
           } else |_| {}
           
           // Create HTTP client
           var client = std.http.Client{ .allocator = allocator };
           defer client.deinit();
           
           // Build headers
           var headers = std.ArrayList(u8).init(allocator);
           defer headers.deinit();
           
           // Add Range header if resuming
           if (start_byte > 0) {
               try headers.writer().print("Range: bytes={d}-\r\n", .{start_byte});
           }
           
           // Make request
           var req = try client.request(.GET, try std.Uri.parse(url), headers.items, .{});
           defer req.deinit();
           
           try req.start();
           try req.wait();
           
           // Handle response
           const status = req.response.status;
           if (status == .partial_content) {
               // Resume working, append to file
               const file = try std.fs.cwd().openFile(dest_path, .{ .mode = .write_only });
               defer file.close();
               try file.seekFromEnd(0);
               // Stream body to file, update progress
           } else if (status == .ok) {
               // Full download, overwrite/create file
               const file = try std.fs.cwd().createFile(dest_path, .{});
               defer file.close();
               // Stream body to file, update progress
           } else {
               return error.DownloadFailed;
           }
       }
       ```
