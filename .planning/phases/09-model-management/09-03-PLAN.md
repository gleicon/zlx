# Phase 09 Plan 03: Background Loading & Open WebUI Integration

## Objective
Enable true background model loading so the server remains responsive while a new model loads. Add API endpoints to start loads, check progress, and cancel. Ensure CORS headers allow Open WebUI to connect from its default port (http://localhost:8081).

## Purpose
Complete the v1.1 UX vision: users can queue model loads without interrupting current inference, check progress via API, and use Open WebUI as their chat interface. This is the final piece for "production-ready" status.

       ```zig
       pub fn handleLoadStatus(req: anytype, res: anytype) !void {
           setCorsHeaders(res);
           if (req.method == .OPTIONS) { res.status = 204; return; }
           
           const manager = manager_mod.getGlobalManager().?;
           
           if (manager.getLoadProgress()) |progress| {
               // Return progress as JSON
               sendJsonResponse(res, 200, json_with_progress);
           } else {
               // No active load
               sendJsonResponse(res, 200, "{\"status\":\"no_active_load\"}");
           }
       }
       ```
    
    3. **POST /v1/models/load/cancel** — Cancel ongoing load:
       ```zig
       pub fn handleCancelLoad(req: anytype, res: anytype) !void {

           if (req.method == .OPTIONS) { res.status = 204; return; }

           manager.cancelLoad() catch |err| {
               return sendError(res, 400, "No active load to cancel", ...);
           };
           
           sendJsonResponse(res, 200, "{\"status\":\"cancelled\"}");
       ```

       ```zig
       pub fn setCorsHeaders(res: anytype, config: ?*const Config) void {

           res.setHeader("Access-Control-Allow-Origin", origin);
       ```
