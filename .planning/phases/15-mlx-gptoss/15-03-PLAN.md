## Reference: openharmony-MLX Tools

From https://github.com/arthurcolle/openharmony-mlx/tree/master/gpt_oss/tools:

**Browser Tool Interface:**
- `search(query: string)` - Search for key phrases
- `open(url: string)` - Open a particular page  
- `find(query: string, page_id: string)` - Find text on a page

**Python Tool Interface:**
- `execute(code: string)` - Run Python code in sandbox
