## Reference: Harmony Format

From https://github.com/openai/harmony:

**Key Concepts:**
- Harmony is a structured conversation format with special tokens
- Supports tool calling, reasoning chains, and multi-turn conversations
- Uses recipient routing for tool calls
- Native to GPT-OSS models (trained specifically on this format)

**Special Tokens:**
```
<|startoftext|>          - Document start
<|endoftext|>            - Document end (EOS)
<|tool_call|>            - Start of tool call
<|/tool_call|>           - End of tool call
<|tool_result|>          - Start of tool result
<|/tool_result|>         - End of tool result
<|recipient|>name<|/recipient|>  - Message recipient
<|reasoning|>             - Start of reasoning chain
<|/reasoning|>            - End of reasoning chain
<|user|>                  - User role marker
<|assistant|>             - Assistant role marker
<|system|>                - System role marker
```

**Message Structure:**
```
<|recipient|>user<|/recipient|>
<|user|>
What's the weather in SF?
<|/user|>
<|recipient|>browser<|/recipient|>
<|tool_call|>
{"url": "https://api.weather.com/sf"}
<|/tool_call|>
<|recipient|>user<|/recipient|>
<|assistant|>
The weather in SF is sunny, 72°F.
<|/assistant|>
```

**Python Reference (openai-harmony):**
```python
from openai_harmony import SystemContent, Message, Conversation, Role
from openai_harmony import load_harmony_encoding, HarmonyEncodingName

# Load encoding
encoding = load_harmony_encoding(HarmonyEncodingName.HARMONY_GPT_OSS)

# Create conversation
system_message = Message.from_role_and_content(Role.SYSTEM, system_content)
user_message = Message.from_role_and_content(Role.USER, "Hello!")
conversation = Conversation.from_messages([system_message, user_message])

# Render to tokens
token_ids = encoding.render_conversation_for_completion(
    conversation, 
    Role.ASSISTANT
)

# Parse completion output
messages = encoding.parse_messages_from_completion_tokens(
    output_tokens,
    Role.ASSISTANT
)
```

**Tool Integration:**
- Tool calls have recipient (browser, python, etc.)
- Tool results are formatted with `<|tool_result|>` tags
- Model expects tool results to continue conversation
- Reasoning is separate from final output

## Architecture

```
src/harmony/
├── harmony.zig          - Core types and interfaces
├── types.zig            - Type definitions (Role, Content, etc.)
├── parser.zig           - Parse Harmony from tokens/text
└── template.zig         - Format conversations to Harmony

Usage Flow:
1. API receives OpenAI-format messages
2. template.zig: Convert to Harmony format
3. tokenizer: Encode Harmony to token IDs
4. Model generates tokens
5. parser.zig: Decode tokens to Harmony messages
6. Extract tool calls if present
7. Execute tools
8. template.zig: Format tool results to Harmony
9. Loop back to model generation
```

       ```zig
       pub const HarmonyParser = struct {
           allocator: std.mem.Allocator,
           
           pub fn init(allocator: std.mem.Allocator) HarmonyParser {
               return .{ .allocator = allocator };
           }
           
           /// Parse Harmony-encoded text into conversation
           pub fn parse(self: *HarmonyParser, text: []const u8) !HarmonyConversation {
               var conversation = HarmonyConversation.init(self.allocator);
               errdefer conversation.deinit();
               
               var i: usize = 0;
               var current_role: ?HarmonyRole = null;
               var current_content = std.ArrayList(u8).init(self.allocator);
               defer current_content.deinit();
               var current_recipient: ?[]const u8 = null;
               
               while (i < text.len) {
                   // Check for special tokens
                   if (try self.parseSpecialToken(text, &i)) |token| {
                       switch (token) {
                           .user_start => current_role = .user,
                           .assistant_start => current_role = .assistant,
                           .system_start => current_role = .system,
                           .user_end, .assistant_end, .system_end => {
                               // Complete current message
                               if (current_role) |role| {
                                   const content = try current_content.toOwnedSlice();
                                   const msg = try HarmonyMessage.initText(self.allocator, role, content);
                                   if (current_recipient) |r| {
                                       msg.recipient = r;
                                       current_recipient = null;
                                   }
                                   try conversation.addMessage(msg);
                                   current_role = null;
                               }
                           },
                           .tool_call_start => {
                               // Parse tool call
                               const tool_call = try self.parseToolCall(text, &i);
                               try conversation.addMessage(tool_call);
                           },
                           .tool_result_start => {
                               // Parse tool result
                               const tool_result = try self.parseToolResult(text, &i);
                               try conversation.addMessage(tool_result);
                           },
                           .recipient_start => {
                               // Extract recipient name
                               current_recipient = try self.parseRecipient(text, &i);
                           },
                           // ... handle other tokens
                       }
                   } else {
                       // Regular text
                       try current_content.append(text[i]);
                       i += 1;
                   }
               }
               
               return conversation;
           }
           
           /// Extract tool calls from assistant output
           pub fn extractToolCalls(self: *HarmonyParser, text: []const u8) ![]ToolCall {
               var tool_calls = std.ArrayList(ToolCall).init(self.allocator);
               errdefer {
                   for (tool_calls.items) |*tc| tc.deinit(self.allocator);
                   tool_calls.deinit();
               }
               
               // Find all <|tool_call|>...<|/tool_call|> blocks
               var i: usize = 0;
               while (i < text.len) {
                   if (std.mem.indexOfPos(u8, text, i, "<|tool_call|>")) |start| {
                       const end = std.mem.indexOfPos(u8, text, start, "<|/tool_call|>") orelse break;
                       const json_content = text[start + "<|tool_call|>".len .. end];
                       
                       // Parse JSON
                       const parsed = try std.json.parseFromSlice(std.json.Value, self.allocator, json_content, .{});
                       defer parsed.deinit();
                       
                       // Extract tool name and arguments
                       const name = parsed.value.object.get("name") orelse ...
                       
                       try tool_calls.append(.{
                           .name = try self.allocator.dupe(u8, name),
                           .arguments = try self.allocator.dupe(u8, json_content),
                       });
                       
                       i = end + "<|/tool_call|>".len;
                   } else {
                       break;
                   }
               }
               
               return tool_calls.toOwnedSlice();
           }
       };
       ```

       ```zig
       /// Convert OpenAI messages to Harmony format
       pub fn formatHarmonyChat(
           self: *HarmonyTemplate,
           messages: []const OpenAIMessage,
           system_tools: ?[]const ToolDefinition,
       ) ![]u8 {
           var output = std.ArrayList(u8).init(self.allocator);
           errdefer output.deinit();
           
           // Start marker
           try output.appendSlice("<|startoftext|>\n");
           
           // System message with tools
           if (system_tools) |tools| {
               try output.appendSlice("<|system|>\n");
               try output.appendSlice("You are a helpful assistant.");
               try output.appendSlice("\n\nYou have access to the following tools:\n");
               for (tools) |tool| {
                   try std.fmt.format(output.writer(), "\n- {s}: {s}\n", .{ tool.name, tool.description });
                   // Add parameter schema
                   try std.json.stringify(tool.parameters, .{}, output.writer());
               }
               try output.appendSlice("<|/system|>\n");
           }
           
           // Format each message
           for (messages) |msg| {
               switch (msg.role) {
                   .system => {
                       try output.appendSlice("<|system|>\n");
                       try output.appendSlice(msg.content);
                       try output.appendSlice("<|/system|>\n");
                   },
                   .user => {
                       try output.appendSlice("<|recipient|>user<|/recipient|>\n");
                       try output.appendSlice("<|user|>\n");
                       try output.appendSlice(msg.content);
                       try output.appendSlice("<|/user|>\n");
                   },
                   .assistant => {
                       if (msg.tool_calls) |tool_calls| {
                           // Format tool calls
                           for (tool_calls) |tc| {
                               try std.fmt.format(output.writer(), "<|recipient|>{s}<|/recipient|>\n", .{tc.function.name});
                               try output.appendSlice("<|tool_call|>\n");
                               try output.appendSlice(tc.function.arguments);
                               try output.appendSlice("\n<|/tool_call|>\n");
                           }
                       } else {
                           try output.appendSlice("<|recipient|>user<|/recipient|>\n");
                           try output.appendSlice("<|assistant|>\n");
                           try output.appendSlice(msg.content);
                           try output.appendSlice("<|/assistant|>\n");
                       }
                   },
                   .tool => {
                       try std.fmt.format(output.writer(), "<|recipient|>{s}<|/recipient|>\n", .{msg.name orelse "tool"});
                       try output.appendSlice("<|tool_result|>\n");
                       try output.appendSlice(msg.content);
                       try output.appendSlice("\n<|/tool_result|>\n");
                   },
               }
           }
           
           // Add assistant prompt for generation
           try output.appendSlice("<|recipient|>user<|/recipient|>\n");
           try output.appendSlice("<|assistant|>\n");
           
           return output.toOwnedSlice();
       }
       ```
