## Integration Architecture

```
HTTP Request (OpenAI format)
    ↓
chatGptossHandler
    - Detect GPT-OSS model
    - Convert to Harmony format
    - Start generation
    ↓
MLXGPTOSSBackend.generate()
    - Load model (if not cached)
    - Generate tokens
    - Parse output for tool calls
    ↓
ToolOrchestrator
    - Extract tool calls from Harmony
    - Execute via ToolExecutor
    - Format results back to Harmony
    - Continue generation
    ↓
Stream response (SSE) or complete JSON
```

## Backend Selection

From Phase 14 (llama.cpp) + Phase 15 (MLX):

```zig
// src/backends/backend.zig - Updated
pub const BackendType = enum {
    mlx,        // Standard MLX (Qwen, Llama)
    llama,      // llama.cpp (DeepSeek, GPT-OSS via GGUF)
    mlx_gptoss, // Native MLX GPT-OSS (this phase)
};

pub fn selectBackend(model_type: []const u8, model_path: []const u8) BackendType {
    if (std.mem.startsWith(u8, model_path, "gpt-oss")) {
        // Prefer native MLX for GPT-OSS
        return .mlx_gptoss;
    } else if (isMoEModel(model_type)) {
        // llama.cpp for other MoE
        return .llama;
    } else {
        // Standard MLX
        return .mlx;
    }
}
```

## Harmony Tool Loop

```
User Request: "What's the weather in SF?"
    ↓
Format to Harmony:
<|recipient|>user<|/recipient|>
<|user|>What's the weather in SF?<|/user|>
<|recipient|>assistant<|/recipient|>
<|assistant|>
    ↓
Generate:
I need to check the weather.
<|recipient|>browser<|/recipient|>
<|tool_call|>{"action": "search", "query": "weather SF"}<|/tool_call|>
    ↓
Parse tool call:
Extract: action=search, query="weather SF"
    ↓
Execute browser.search("weather SF")
Result: "San Francisco: 72°F, sunny"
    ↓
Format result:
<|recipient|>browser<|/recipient|>
<|tool_result|>
San Francisco: 72°F, sunny
<|/tool_result|>
<|recipient|>assistant<|/recipient|>
<|assistant|>
    ↓
Continue generation:
The weather in SF is 72°F and sunny.
<|/assistant|>
    ↓
Return to user
```

    "tool_choice": "auto",    // Optional

}

Response (streaming):
data: {"choices": [{"delta": {"content": "The weather"}}]}
data: {"choices": [{"delta": {"content": " in SF is 72°F"}}]}
