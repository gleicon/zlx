## Reference: GPT-OSS Weight Format

From https://huggingface.co/openai/gpt-oss-20b and openharmony-MLX:

**Model Structure:**
- `original/` - Safetensors checkpoint files (11GB for 20B)
- `config.json` - Model configuration
- `tokenizer.json` - Tokenizer vocabulary
- `metal/` - Pre-converted MLX weights (optional)

**MXFP4 Quantization:**
- Native to GPT-OSS MoE layers
- Block quantization: 32 values per block
- Each block has scale factor
- Values packed: 2x FP4 per byte
- Dequantize to BF16 for computation

**MXFP4 Tensor Format:**
```python
# From openharmony-MLX
class MXFP4Tensor:
    blocks: np.ndarray  # uint8, packed FP4 values
    scales: np.ndarray  # float32, block scales
    block_size: int = 32
```

**Dequantization Formula:**
```
for each block:
    scale = scales[block_idx]
    for each value in block:
        fp4 = unpack_uint8(blocks[block_idx * block_size + i])
        bf16 = fp4_to_bf16(fp4) * scale
```

## MXFP4 Implementation

**GPU Kernel (Metal):**
```metal
kernel void mxfp4_dequantize(
    device const uint8_t* blocks [[buffer(0)]],
    device const float* scales [[buffer(1)]],
    device bfloat16_t* output [[buffer(2)]],
    constant int& num_blocks [[buffer(3)]],
    constant int& block_size [[buffer(4)]],
    uint tid [[thread_position_in_grid]]
)
{
    int block_idx = tid / block_size;
    int idx_in_block = tid % block_size;
    
    uint8_t packed = blocks[tid / 2];
    uint8_t nibble = (tid % 2 == 0) ? (packed & 0x0F) : (packed >> 4);
    
    float scale = scales[block_idx];
    float value = fp4_to_float(nibble) * scale;
    
    output[tid] = float_to_bfloat16(value);
}
```

**CPU Fallback:**
```zig
pub fn dequantizeMXFP4CPU(
    blocks: []const u8,      // Packed FP4 values
    scales: []const f32,     // Block scales
    output: []f16,           // BF16 output
    block_size: usize,
) void {
    for (0..scales.len) |block_idx| {
        const scale = scales[block_idx];
        const block_start = block_idx * (block_size / 2);
        
        for (0..block_size) |i| {
            const byte_idx = block_start + (i / 2);
            const nibble = if (i % 2 == 0) 
                blocks[byte_idx] & 0x0F 
            else 
                blocks[byte_idx] >> 4;
            
            const fp4_val = fp4_table[nibble];
            output[block_idx * block_size + i] = fp4_val * scale;
        }
    }
}
```
