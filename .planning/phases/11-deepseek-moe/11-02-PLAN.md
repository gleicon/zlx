**Key context from STATE.md:**
- MLA is DeepSeek's key innovation: compresses KV cache by ~90%
- Standard MHA stores: K [batch, seq, heads, head_dim] + V [batch, seq, heads, head_dim]
- MLA stores: single latent vector [batch, seq, latent_dim] where latent_dim << heads × head_dim
- Joint compression of K and V with low-rank projections

**DeepSeek-V2 Configuration:**
- hidden_size: 4096
- num_attention_heads: 16
- head_dim: 128
- latent_dim: 512 (compressed)
- Compression: 4096 → 512 = 8x for queries, 8192 → 512 = 16x for KV

**Dependencies:** Plan 11-01 must be complete (mlx-c v0.4.x working)
</context>

  <action>
    Complete CompressedKVCache implementation:
    
    1. Implement update() method:
       ```zig
       pub fn update(self: *CompressedKVCache, new_kv_latent: mlx.Array) !void {
           const new_seq_len = try new_kv_latent.dim(1);
           
           if (self.cached_latent == null) {
               // First time - initialize
               self.cached_latent = try mlx.copy(new_kv_latent);
               self.seq_len = new_seq_len;
           } else {
               // Append new tokens
               const current = self.cached_latent.?;
               self.cached_latent = try mlx.concatenate(&.{ current, new_kv_latent }, 1);
               mlx.arrayFree(current);
               self.seq_len += new_seq_len;
           }
       }
       ```
    
    2. Implement getCached():
       ```zig
       pub fn getCached(self: *CompressedKVCache) !mlx.Array {
           if (self.cached_latent) |cache| {
               return cache;
           }
           return error.EmptyCache;
       }
       ```
    
    3. Implement clear():
       - Free cached_latent if not null
       - Set to null
       - Reset seq_len to 0
    
    4. Implement memoryUsage():
       - If cached: return mlx.arrayNbytes()
       - Else: return 0
    
    5. Add capacity checking (optional for v1)
  </action>
