**DeepSeek Chat Format:**
```
System: You are a coding assistant
User: Write a Python function
Assistant: Here's a function:
def sort_list(arr):
    return sorted(arr)
User: Make it in-place
Assistant: Sure! Here's an in-place version:
def sort_inplace(arr):
    arr.sort()
    return arr
```

**Key Differences from OpenAI:**
- No JSON structure, plain text with role prefixes
- System prompt at top without explicit "system" marker
- "User:" and "Assistant:" as role indicators
- No special tokens for turns

       ```zig
       pub fn formatDeepSeekChat(allocator: std.mem.Allocator, messages: []const Message) ![]const u8 {
           var result = std.ArrayList(u8).init(allocator);
           defer result.deinit();
           
           for (messages) |msg| {
               switch (msg.role) {
                   .system => {
                       // System prompt at top, no special marker
                       try result.appendSlice(msg.content);
                       try result.append('\n');
                   },
                   .user => {
                       try result.appendSlice("User: ");
                       try result.appendSlice(msg.content);
                       try result.append('\n');
                   },
                   .assistant => {
                       try result.appendSlice("Assistant: ");
                       try result.appendSlice(msg.content);
                       try result.append('\n');
                   },
               }
           }
           
           // Add assistant prefix for generation
           try result.appendSlice("Assistant: ");
           
           return result.toOwnedSlice();
       }
       ```
    
    2. Add unit tests:
       - Test system prompt at top
       - Test user/assistant alternation
       - Test trailing "Assistant: " for generation
       - Test with MessageContent array type
