The CLI already has --turboquant flags implemented:
- --turboquant: Enable compression
- --turboquant-bits N: 3 or 4 bits
- --turboquant-adaptive N: First/last N layers in FP16

The Config struct in main.zig has:
```zig
turboquant_enabled: bool = false,
turboquant_bits: u4 = 4,
turboquant_adaptive: u8 = 4,
```
