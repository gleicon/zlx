## Key Context from Phase 12 FIX-01

DeepSeek uses mlx-community format with 3-component quantized weights:
- `.weight`: Packed 4-bit integers (2 values per byte)
- `.biases`: Zero points per group (float32)
- `.scales`: Scale factors per group (float32)

Current stub in loader.zig (line ~300):
```zig
fn mapQuantizedWeight(weights_hash: std.StringHashMap(mlx.Array), key_base: []const u8) !QuantizedWeight {
    // Returns raw components WITHOUT dequantization
    return QuantizedWeight{
        .weight = weights_hash.get(key_base ++ ".weight"),
        .biases = weights_hash.get(key_base ++ ".biases"),
        .scales = weights_hash.get(key_base ++ ".scales"),
    };
}
```

This needs to dequantize: `reconstructed = (quantized - biases) * scales`
</context>

  <action>
    Create new dequantization module implementing 4-bit affine dequantization per MLX spec.
    
    Algorithm:
    ```
    // Input: packed 4-bit weights (2 nibbles per byte), biases, scales
    // Group size: typically 32 or 64 (from weight metadata)
    // Output: float16 or float32 reconstructed weights
    
    for each group:
      scale = scales[group_idx]
      bias = biases[group_idx]
      for each element in group:
        quantized_nibble = (packed_byte >> (4 * (element_idx % 2))) & 0xF
        // 4-bit values are typically unsigned 0-15 or signed -8 to 7
        // Check MLX convention (usually signed: -8 to 7)
        signed_val = @as(i8, @intCast(quantized_nibble)) - 8  // center at 0
        dequantized = (@as(f32, signed_val) - bias) * scale
    ```
    
    Implementation requirements:
    1. Define `DequantizeConfig` struct with group_size (32 or 64) and output_dtype
    2. Implement `dequantizeAffine4Bit()` function accepting MLX arrays
    3. Support both CPU and Metal GPU paths (GPU preferred for large tensors)
    4. Handle both signed and unsigned 4-bit conventions
    5. Return properly shaped MLX array matching original weight dimensions
    
    Integration with MLX:
    - Use mlx.arrayNewData() for output
    - Use mlx.eval() to execute on GPU
    - Proper memory management with mlx.arrayFree()
    
    Export public functions:
    - `pub fn dequantizeAffine4Bit(weights: mlx.Array, biases: mlx.Array, scales: mlx.Array, config: DequantizeConfig) !mlx.Array`
  </action>
